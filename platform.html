核心平台

覆盖从材料生成、性质筛选到动力学稳定性验证和实验方案设计的关键环节。

声子谱预测

PhononBench

晶体声子谱分钟级快速计算平台

通过接近DFT精度的声子计算，对AI生成晶体开展高通量动力学稳定性评估，为晶体生成模型提供物理可实现性基准。

  • 大规模动力学稳定性基准
  • 分钟级在线声子谱预测
  • 开放数据与高通量工作流
在线使用 GitHub 论文

材料逆向设计

InvDesFlow

功能材料发现与逆向设计平台

将晶体生成、性质预测、第一性原理计算和主动学习连接为可迭代闭环，用于面向目标性能发现和优化功能材料。

  • 20万级材料数据基础
  • 生成与筛选闭环迭代
  • 支持高温超导等目标性质
在线使用 GitHub 论文

材料垂域大模型

Perovskite-R1

钙钛矿太阳能电池实验方案设计模型

利用高级推理和文献知识挖掘辅助发现钙钛矿前驱体添加剂，形成面向稳定性提升和器件性能优化的实验设计建议。

  • 领域知识检索与推理
  • 前驱体添加剂智能设计
  • 面向实验验证的方案生成
GitHub 论文

磁性材料预训练模型

MatAltMag

交错磁性材料快速筛选模型

基于晶体结构图神经网络与少样本学习，自动预测并发现具有不同电子和拓扑性质的新型交错磁性材料。

  • 晶体结构智能表征
  • 少样本高效预测
  • 电子与拓扑性质联合筛选

应用案例

平台已用于超导材料筛选、交错磁性发现和钙钛矿实验策略设计。

01

高温BCS超导材料筛选

利用InvDesFlow筛选潜在高温超导材料，其中Li2AuH6的常压超导转变温度预测约为140 K。

  • 材料发现
  • 超导材料
  • AI预测
02

交错磁性材料发现

MatAltMag发现50种新的交错磁性材料，其中包括4种此前未报道的i波交错磁性材料。

  • 交错磁性
  • 预训练微调
  • 高效筛选

钙钛矿实验设计
